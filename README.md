# Comics DOMIX

Public React/Vite web project for a comic illustration and creative services site.

## What this project shows

- Single-page application structure with React and Vite.
- Responsive UI components organized by page sections.
- Tailwind CSS styling with reusable UI primitives.
- Form-oriented interaction flow for service requests.
- Use of production assets, routing, metadata, and animation libraries.

## Tech stack

- React
- Vite
- Tailwind CSS
- Radix UI
- Framer Motion
- Lucide React
- PocketBase client

## Repository status

This repository is kept as a public portfolio sample. It is not intended to expose client data, private credentials, production environment variables, or commercial datasets.

## Why it matters

The project demonstrates practical frontend implementation: assembling a branded user experience, structuring reusable components, and preparing a web interface that can evolve into a real customer-facing product.

## Local development

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
